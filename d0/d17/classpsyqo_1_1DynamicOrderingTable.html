Detailed Description

template<Safe safety = Safe::Yes>
class psyqo::DynamicOrderingTable< safety >

An ordering table whose bucket count is chosen at runtime.

Behaves like OrderingTable, for when the number of buckets is only known at runtime, for example when it comes from loaded data. It does not own its storage: the caller provides buckets + 1 entries, which must outlive the table and every frame the GPU reads it in. Schedule it with GPU::chain.
