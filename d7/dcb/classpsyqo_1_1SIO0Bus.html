Detailed Description

Ownership arbiter for the SIO0 serial bus.

The controller (pad) and the memory card share a single SIO0 bus and cannot drive it at the same time: two owners clocking the line at once corrupt each other's transfers. A memory card operation can span many sector transfers over many frames, so it takes this lock for its whole duration, and AdvancedPad (and SimplePad) consult it each frame.

The lock is re-entrant: a filesystem operation holds it across all of its sector transfers even though each blocking sector transfer also takes it.

Holding the lock does not mean the bus is busy. Between two sector transfers the card is deselected and the bus is idle for about a frame. A holder that knows this can open a poll window with allowPollsBetweenTransfers; the asynchronous filesystem does. With the window open, a pad poll runs whenever no transfer is in flight, and a poll that arrives during a transfer is left pending and serviced by the card driver before it issues the next one. Without the window, the pad stands down for as long as the lock is held.

There is a single bus, so the state is static. Ownership and the poll window are only mutated from the main thread. The in-flight flag is set from the main thread when a transfer starts and cleared by the transfer engine's interrupt when it ends; since transfers only start on the main thread, a main-thread reader that sees it clear cannot have a transfer start under it.
