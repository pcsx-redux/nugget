SCPH-1000, SCPH-1001, SCPH-5501 (two consoles), SCPH-7001 and SCPH-9002, build 48faf1f9.

Each cell writes a register, waits N nops (N = 0..3) and runs the command. Letters, one per N: O / N the outputs match the old / new value, o / n the same with the written register left out (the late write landed over the command's own result), X some outputs old and some new. A0..A3 is the word of the 16-byte cache line the sequence starts at; U is uncached. "min N" is the smallest N from which every cached result is new, at every offset on every console.

Seven letters change with the offset, all at N=1 (N at A0, the old value or X at A1..A3): RTPT R31R32, RTPT TRZ, INTPL IR1, INTPL RFC, MVMVA(LC,IR,BK) IR1 and RBK, GPL IR1. The SCPH-9002 swaps DPCT RGB0 and RGB1 at N=0..1 (RGB0 NN, RGB1 XX); the others give the reverse. Otherwise every cached letter is the same on all six consoles. The uncached column is the SCPH-5501 #3; a few uncached letters differ between consoles. The program checks every cached letter that is the same at all four offsets on all six consoles, and passes on all six. It exits 0 when every checked letter matches, 2 when only X letters differ (GWU-COARSE-PASS: a model with one delay per command and register, without per-term read timing), and 1 otherwise.
