Detailed Description

The cursor marker, as a triangle you can draw directly.

Already rotated: tip points OUTWARD along the cursor's own spoke, at the box it currently selects, so it turns as the crank turns. left and right are the base corners. The library computes these because the app has no cheap way to rotate a shape without a trig table of its own.
