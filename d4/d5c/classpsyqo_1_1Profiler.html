Detailed Description

Scoped profiler: timed scopes recorded into a ring buffer.

A PSYQO_PROFILE_SCOPE("name") statement times the rest of its enclosing block and records the zone, start, end, vsync count and nesting depth into a ring buffer when the block exits. Nothing is linked unless the program uses it, and nothing is recorded until a buffer is installed:

static psyqo::Profiler::Buffer<1024> s_profile;
// once, after the GPU is initialized:
psyqo::Profiler::install(s_profile);
// anywhere:
void Renderer::render() {
PSYQO_PROFILE_SCOPE("render");
...
}

PCSX-Redux reads the buffer live and draws it as a timeline in its Scope Profiler window. On a console, forEach or dumpPCDRV gets the entries out.

Time comes from root counter 2, which install claims and sets to free-run on the system clock, combined with psyqo's hblank counter on root counter 1. Every time is in system clock cycles, exact for scopes up to about 4 seconds long. The layout of the buffer, and how the two counters combine, are in common/hardware/pcsxprof.h.

Scopes are meant for the main loop. The nesting depth is one global, so a scope inside an interrupt handler, or one held across a coroutine suspension while another scope runs, records the wrong depth. The times stay right. A scope costs about 160 cycles in PCSX-Redux's interpreter (about 60 to begin, 100 to end), almost all outside its own measured span but inside the span of any scope around it. So a short function reads about that much lower than a per-function profile of the same build, which also counts the scope itself.

Runs function count times, timing each run.

Each run is recorded under zone like a scope, and the result holds the run times in cycles. The cost of reading the counters twice is subtracted. Needs an installed buffer: without one, nothing runs and the result is empty. total wraps past 2^32 cycles, a bit over two minutes.

inlinestatic

Claims root counter 2 and starts recording into the buffer.

Call it after the GPU is initialized, since the elapsed times depend on the hblank counter it sets up. It spends about 260 lines (one frame) measuring how many cycles a line takes. Under PCSX-Redux, the buffer is also registered so the emulator can read it. Installing another buffer replaces the first one.
