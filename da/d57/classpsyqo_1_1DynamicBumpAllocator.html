Detailed Description

template<Safe safety = Safe::Yes>
class psyqo::DynamicBumpAllocator< safety >

A bump allocator whose capacity is chosen at runtime.

Same interface as BumpAllocator, for when the capacity is only known at runtime. It does not own its storage: the caller provides size bytes, 4-byte aligned, which must outlive every fragment allocated from it.
