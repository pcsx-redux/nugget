31/* What the previous program left in the GPU, saved by getVRAM() before it
32 resets the GPU, at a fixed address right after the VRAM copy so the host
33 can read both back. GPUSTAT carries the display mode; the GP1(10h) words
34 are the texture window (index 2), drawing area top-left (3) and
35 bottom-right (4), drawing offset (5) and GPU version (7, stale GPUREAD on
36 the original 160-pin GPU). The display start address (GP1(05h)) has no
37 readback, so it is not here. */
